Artemis Financial is a company that creates financial plans for its clients who want to improve the security of their current software to safeguard customer data, given the sensitive nature of the data they deal with. I scanned their software with the OWASP Dependency-Check tool to find potential security vulnerabilities and also manually reviewed their code for issues or weaknesses. Coding securely not only allows future developers a secure foundation to build from, but it is also essential for client data, as well as the company to ensure trust with clients and avoid legal ramifications. One area I found challenging was getting the SSL certificate and keystore to work correctly after I encountered password-related issues to get HTTPS working. Ultimately, troubleshooting the issue allowed me to resolve it, and I found it was isolated to the IDE I was using. 

I improved the existing code from an HTTP connection to HTTPS with a PKCS12 keystore and implemented a SHA-256 hashing algorithm to generate checksums. These changes ultimately helped to protect the communications by verifying data integrity as well as secure data transfer over HTTPS, which is vital for this type of application. I will continue to use the Dependency-Check tool for all future projects for testing, and for this application, I made sure it was functional by testing the program afterward to ensure it ran. Then I ran the existing code through the Dependency-Check tool and again after I refactored to ensure I added no new vulnerabilities and verified the SHA-256 checksum was generated as well. I used the Dependency-Check tool, which will be extremely useful in future projects or personal ones, as well as Maven and Java’s Keytool program to generate certificates. This project demonstrates my ability to enhance the security of a project through cryptographic hashing, HTTPS, and conducting dependency analysis, and to put it all into plain English for non-technical people to understand.
